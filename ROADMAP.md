# Roadmap

This file tracks the current direction of the project.

It is not a promise. It is a working list of likely next steps.

## Near Term

- Improve the public README with screenshots, media, and a more personal voice.
- Keep README snapshots in `readme-history/` as public milestones.
- Continue refining the menu bar app workflow.
- Keep the repo public-safe while local experimentation continues.
- Decide on a better long-term project name.

## Product / UX

- Make the app easier to understand for a new user at first launch.
- Improve the search/result presentation in the menu bar UI.
- Make OCR-only and semantic modes easier to compare and explain.
- Add more polished screenshots and visual examples.

## Documentation

- Add screenshots/assets for the public README.
- Clarify setup paths for someone who is not using the exact same machine.
- Keep user-facing docs separate from internal project notes.

## Technical

- Continue improving indexing reliability and search quality.
- Keep generated files and local-only data out of git.
- Preserve the local-first privacy model while using Gemini only where it adds value.

## Open Questions

- Final product name
- Final repo name
- Which screenshots or media should become part of the public story
- Whether more internal notes should stay in tracked files or move to ignored local notes
